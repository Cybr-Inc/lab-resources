AZURE PROGRESS SITE

Keep this complete folder on your computer. The files work together.

The starter files are:

- index.html: the home page
- styles.css: the design for all pages
- day-01.html: the first course entry
- entry-template.html: the source for each new entry

To add a course entry:

1. Copy entry-template.html.
2. Name the copy day-NN.html. Replace NN with the two-digit course day.
3. Replace the uppercase starter text in the new file.
4. Add a link to the new page in index.html.
5. Upload the new page and the changed index.html file.

You can ask an LLM to help with the text or HTML. Use this prompt:

I am adding a page to my public Azure progress site.

Today's lesson was:
[LESSON TITLE]

My result was:
[RESULT]

My evidence was:
[EVIDENCE]

Customize the attached entry-template.html file with this information.

Keep the stylesheet link, navigation, file name, and CSS classes.
Do not add JavaScript or external services.
Do not include credentials, account IDs, tenant IDs, access tokens, private email addresses, or other private information.
Return the complete HTML file only.
