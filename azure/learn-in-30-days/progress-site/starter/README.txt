AZURE LEARNING BLOG

Keep this complete folder on your computer. The files work together.

The starter files are:

- index.html: the post list
- styles.css: the shared design
- day-01.html: the first published post
- entry-template.html: the source for each new post

To add a post:

1. Copy entry-template.html.
2. Name the copy day-NN.html. Replace NN with the two-digit course day.
3. Replace the uppercase starter text in the new file.
4. Add a post row to index.html.
5. Upload the new post, index.html, and styles.css.

Keep the site simple. Write one short paragraph for each section.

You can ask an LLM to help with the text or HTML. Use this prompt:

I am adding a post to my public Azure learning blog.

Today's lesson was:
[LESSON TITLE]

My result was:
[RESULT]

My evidence was:
[EVIDENCE]

Customize the attached entry-template.html file with this information.

Keep the stylesheet link, file name, HTML structure, and CSS classes.
Do not add JavaScript, external services, tracking, or contact forms.
Do not include credentials, account IDs, tenant IDs, access tokens, private email addresses, or other private information.
Return the complete HTML file only.
