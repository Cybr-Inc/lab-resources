# CloudOps runbooks

Operational runbooks for Day 13 of Learn Azure in 30 Days.

- `customer-api-503.md` covers an HTTP 503 after a release.
- `entra-sign-in-failure.md` covers repeated Microsoft Entra sign-in failures.
- `storage-upload-failure.md` covers a failed Blob Storage upload.
- `cloudops-runbooks.zip` contains the three Markdown runbooks for portal upload.
